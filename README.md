# Big Challenge Prof

Big Challenge Prof is a C programming project developed as part of an academic assignment.  
This project is structured modularly using separate source, header, and data directories, and is built using a Makefile.

---

## 📁 Project Structure
```bash
Big-Challenge-Prof
│   makefile
│   README.md
│
├───bin
│       out.bin
│
├───data
│       1k.txt
│       50k.txt
│
├───docs
│       PROJECT BIG CHALLENGE PROF.docx
│       PROJECT BIG CHALLENGE PROF.pdf
│
├───include
│       fileHandling.h
│       globals.h
│       parsing.h
│       structure.h
│       view.h
│
└───src
        fileHandling.c
        main.c
        parsing.c
        structure.c
        view.c
```
---

## ⚙️ Requirements
This Project is compiled using:
- GCC 13.3.0
- GNU Make 4.4.1
---

## 🛠️ Build Instructions
To compile the project, run:
```
make
```
---

## ▶️ Usage
```
./program
```
